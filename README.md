## 🚀 Como estudar

1. Escolha uma matéria no mapa acima.
2. Abra o `README.md` da matéria e siga o roteiro: **vídeo → aula → slides → exercícios**.
3. Sempre que algo parecer estranho, confira no vídeo original da professora.
